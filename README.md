# kurpati

Лендинг «Курпаты». Next.js 16, React 19, TypeScript. Структура согласована с соседними проектами Livadia и Bereg.

## Локальный запуск

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:3010. Для первого открытия нужен запущенный сервер.

## Проверки

```bash
npm run check
npm run build
npm run pages
npm run test:export
```

## Обратный звонок

Все основные кнопки открывают форму с именем, телефоном и согласием. Бронирование, календарь и оплата отсутствуют. По умолчанию отправка выключена. Форма явно показывает демонстрационный статус.

Настройки находятся в .env.example. Для реального приёма нужно указать оператора в документах, настроить получателя, включить оба флага LEADS_ENABLED и NEXT_PUBLIC_LEADS_ENABLED и проверить доставку. Сервер сохраняет заявки в исключённую из Git папку .data. Telegram используется только при заданных переменных получателя.

GitHub Pages не запускает серверный API. Для отправки со статической версии нужен отдельный разрешённый обработчик и NEXT_PUBLIC_LEAD_ENDPOINT. Без него форма остаётся демонстрационной.

## SEO

Подготовлены metadata, canonical, Open Graph, Twitter Card, JSON-LD, sitemap, robots, favicon и webmanifest. Локальная версия закрыта от индексации. Для публикации нужны NEXT_PUBLIC_SITE_URL, корректный NEXT_PUBLIC_BASE_PATH и явный SITE_NOINDEX=0.

В структурированных данных отсутствуют неподтверждённые цены, рейтинги, часы работы и предложения номеров.

## GitHub Pages

```bash
npm run pages
```

Команда собирает out и подготавливает локальную ветку gh-pages. Она ничего не отправляет в GitHub. Префикс проекта: /kurpati. Проверка npm run test:export запускается после npm run pages.

Workflow Publish reviewed site запускается только вручную после проверки правок. Отправка исходников в main запускает проверки, но не публикацию.

## Материалы

На сайте используются реальные архивные фотографии из собранного пакета. Подпись сайта удалена программной ретушью на копиях. Исходные исследования и большие архивы исключены из Git. Реестр выбранных изображений находится в src/lib/media.json.

Текущий приём гостей, актуальное состояние помещений и состав услуг не подтверждены. Условия размещения уточняются у представителя. Перед публичным запуском необходимо согласовать актуальность, права на выбранные фотографии и сведения получателя заявок.

Сборка изображений из локального исследования: node scripts/prepare-assets.mjs. Для обычного запуска она не нужна, готовые веб-изображения входят в репозиторий.

## Карта окружения

Карта выполнена в стиле карты проекта Livadia. Реальные береговая линия, дороги, здания и парки получены через официальный API OpenStreetMap 9 ноября 2026 года. Карта не использует генеративную графику. Геоданные распространяются по ODbL, атрибуция сохранена на странице и в SVG.

Готовая карта: public/assets/maps/kurpati-coast.svg. Метки и проекция: src/lib/map.ts. Компонент: src/components/LocationMap.tsx. На телефоне карта листается внутри блока. Метки и список мест открывают соответствующие координаты в Яндекс Картах.

Локальные исходные выгрузки находятся в исключённой из Git папке research/map. Повторная отрисовка: node scripts/prepare-map.mjs. Готовый SVG входит в репозиторий, исходные геоданные для обычной сборки не требуются.
